# Documentation

Project documentation for the To-Do List backend. Every change that touches
code must also update at least one document in this folder (see
[CONTRIBUTING.md](CONTRIBUTING.md)).

| Document | Purpose |
|---|---|
| [CONTRIBUTING.md](CONTRIBUTING.md) | Branch and pull request workflow, commit message format, the "no code without docs" rule and how to enable the Git hooks. |
| [CHANGELOG.md](CHANGELOG.md) | Every notable change, grouped by type. Source for the final README summary. |
| [deployment.md](deployment.md) | How to run the stack locally and the requirements for a real deployment (HTTPS, environment, secrets). |
| [team3/](team3/README.md) | One report per Team 3 member: issues found, fixed and left pending, with evidence. |

Reports inherited from previous teams live at the repository root:

- `SECURITY_REPORT.md` and `SECURITY_REPORT_ACTUALIZADO.md` (Team 2 security work).
- `Tipado_Report.md` (Team 2 type checking report).
